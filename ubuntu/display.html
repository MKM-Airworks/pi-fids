Pi-FIDS V2 表示端末 / Ubuntu Display

日本語

  1. Ubuntu 24.04 LTS Desktopの表示に使うアカウントでログインします。Python 3、tzdataとChromium、ChromeまたはEdgeが必要です。
  2. 管理PCの http://管理PCのLANアドレス:8805/downloads からUbuntu版を取得し、展開します。
  3. 管理者から端末専用の connection.json を受け取り、展開先で次を実行します。sudoは不要です。 
    python3 install.py --connection /path/to/connection.json
  4. 今すぐ表示するには、インストーラーが表示したコマンドを実行します。再起動後は、同じユーザーでデスクトップにログインし、Kiosk画面と受信を確認します。受信サービスの状態は systemctl --user status pi-fids-display で確認できます。

English

  1. Sign in to Ubuntu 24.04 LTS Desktop with the display account. Python 3, tzdata and Chromium, Chrome or Edge are required.
  2. Open http://MANAGER-LAN-IP:8805/downloads on the display PC. Download and extract the Ubuntu display kit.
  3. Obtain the terminal-specific connection.json from your administrator. Run this command from the extracted directory, without sudo: 
    python3 install.py --connection /path/to/connection.json
  4. To start the kiosk now, run the command printed by the installer. After restarting, sign in to the same desktop account and confirm kiosk startup and flight reception. To check the receiver service, run systemctl --user status pi-fids-display.
