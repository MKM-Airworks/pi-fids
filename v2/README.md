# Pi-FIDS V2

初期対象はSHI・ROR。既存Windows端末のOSを入れ替えず、Raspberry Piと共通の受信・表示処理を使います。V2はGoogle Sheetsを使用しません。

このブランチには、Mac上で確認できる初期試作があります。リポジトリ直下のV1コードは保全し、V2はこのディレクトリ内で開発します。

## 初期試作の起動

Python 3.9以上で、追加ライブラリなしで起動できます。

```sh
cd v2
python3 -m pifids
```

管理画面は `http://127.0.0.1:8800/`、表示画面は `http://127.0.0.1:8800/display?airport=SHI` です。RORは空港指定を `ROR` に変更します。データは標準で `~/.pifids-v2/prototype.sqlite` に保存します。`--database` と `--port` で変更できます。

試作ではSHI/ROR別の便追加、下書きと公開の分離、公開版の永続保存、便ごとの言語順序、表示側の空港ロゴURL・言語・切替秒数を確認できます。画面文言の言語切替に対応し、行先名の翻訳データはまだ未実装です。

localhost限定の試作です。LAN公開、認証、MKM Flight Web接続、正本切替、画像ダウンロード・永続キャッシュ、Windows配布と実機検証は未実装です。ロゴURLは表示確認用で、正式な画像配信の実装ではありません。

```sh
cd v2
python3 -m unittest discover -s tests
```

## 構成

| 領域 | 役割 |
| --- | --- |
| `manager/`（実装予定） | ローカル編集・公開、LAN配信、表示指示、保存、復旧 |
| `client/`（実装予定） | 共通受信、キャッシュ、便一覧・カウンター・搭乗口表示 |
| `shared/`（実装予定） | データ契約、検証、空港時刻、公開版識別 |
| `cloud/`（実装予定） | Webメイン、バックアップ受付、復旧、正本管理 |
| `deploy/`（実装予定） | Windows x86/x64・Piの導入と自動起動 |
| `docs/` | 設計と開発順序 |

## 対応対象

- Windows 10 x86 / x64
- Windows 11 x64
- Raspberry Pi（OS・機種を実機検証時に確定）

Windowsの配布パッケージと実行環境はx86/x64を分けます。互換性はまだ未検証です。Macでは共通機能の開発を先行します。

詳細は[設計方針](docs/architecture.md)と[開発順序](docs/roadmap.md)を参照してください。

## 端末ごとの表示切替

管理画面で画面ID、カウンター／搭乗口、航空会社名を指定します。対象画面は `/display?airport=ROR&displayId=gate-01` のように開き、約5秒間隔で指示を取得します。「標準の便一覧に戻す」で解除できます。空港・画面IDごとに指示を永続保存します。端末のローカル設定も画面ID別です。航空会社表示は文字のみの初期実装です。ロゴ、便割当、クラス、矢印、端末からの反映応答は未実装のため、適用後は対象画面で確認します。
