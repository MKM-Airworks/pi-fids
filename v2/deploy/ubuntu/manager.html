Pi-FIDS V2 管理PC / Ubuntu Manager

日本語

  1. Ubuntu 24.04 LTSで、管理に使うユーザーでログインします。Python 3とtzdataが必要です。アーカイブをすべて展開します。
  2. 展開先で次を実行します。ROR、タイムゾーン、LAN IPは設置先の値に置き換えてください。インストーラーはsudoなしで実行します。 
    python3 install.py --airport ROR --timezone Pacific/Palau --lan-address 192.168.11.20
  3. 管理PC自身で http://127.0.0.1:8800/ を開き、初回管理者を登録します。③端末の設定で、表示端末ごとに接続設定ファイルを発行します。
  4. 表示PCに http://管理PCのLANアドレス:8805/downloads を案内します。Windows用とUbuntu用の表示アプリを選べます。接続設定は別途渡します。
  5. 再起動後に同じユーザーでログインし、systemctl --user status pi-fids-manager と配布ページの応答を確認します。ログイン前からサービスを動かす運用では、設置先管理者がユーザーサービスのlingerを設定してください。

English

  1. Sign in with the account that will operate Pi-FIDS on Ubuntu 24.04 LTS. Python 3 and tzdata are required. Extract the whole archive.
  2. Run the following from the extracted directory. Replace the station code, IANA time zone and LAN IP. Run without sudo. 
    python3 install.py --airport ROR --timezone Pacific/Palau --lan-address 192.168.11.20
  3. On the manager, open http://127.0.0.1:8800/ and register the initial administrator. Use Terminal settings to issue a separate connection file for each display.
  4. On each display PC, open http://MANAGER-LAN-IP:8805/downloads and select the Windows or Ubuntu display kit. Deliver the connection file separately.
  5. After a restart, sign in with the same account, check systemctl --user status pi-fids-manager, and open the download page. For service startup before login, the site administrator can enable user lingering.
