# Pi-FIDS 共通インストーラー

Windows 10/11 64bit用。管理PC・表示端末の共通インストーラーです。SHI/ROR専用ではなく、設置する空港の3レターコードとIANAタイムゾーンを指定します。Windowsログイン後の自動起動を設定します。

## 管理PC

1. 管理PCで使うWindowsユーザーで `PiFids-Setup-Windows-x64.exe` を開きます。
2. 「管理PC」を選び、空港コード、タイムゾーン、管理PCのLAN IPv4アドレスを入力します。
3. 「インストール」を押します。管理画面・読取専用のLAN配信・時刻サーバー・自動起動が設定されます。
4. 管理画面で便と画像を登録します。
5. デスクトップの「Pi-FIDS Add Display」を開き、表示端末名・ID・用途・画像を選ぶと、端末専用の接続ファイルが発行されます。

管理PCのIPは固定または予約し、設置LANはWindowsの「プライベート」ネットワークにします。管理画面は localhost:8800、読取専用配信は指定したLANアドレスの8805番、時刻配信はUDP123番です。管理操作はその管理PCで行います。

タイムゾーン例：日本の空港＝Asia/Tokyo、パラオ＝Pacific/Palau、バンコク＝Asia/Bangkok。インストーラーではリスト以外のIANAタイムゾーンも入力できます。夏時間がある地域は日付に応じたオフセットを使います。空港コードに対応するタイムゾーンを設置者が確認してください。

MKM Flight Webの顧客・空港・配信権限は別途設定します。インストールだけでWebの権限は追加されません。私有の data/web-connection.json と、その credentialFile を配置すると管理サービスの次回起動からWeb接続を利用できます。これらは共通インストーラーに含めません。

## 表示端末

1. 対象端末の専用接続ファイルを管理PCからコピーします。
2. 同じインストーラーを開き、「表示端末」を選択します。
3. 「選択」で接続ファイルを指定し、「インストール」を押します。
4. 表示端末を再起動し、同じWindowsユーザーでログインして自動表示を確認します。
5. 管理PCから表示を切り替え、時計・便一覧・画像を確認します。

接続ファイルに空港・タイムゾーン・端末ID・接続先・端末専用キーが入っています。表示端末で空港を再入力しないため、管理側との入力違いを避けられます。

## 設置・保守

- Microsoft Edgeと64bit Windowsが必要です。Raspberry Pi用のインストーラーではありません。
- 必ず設置に使うWindowsユーザーで実行してください。別アカウントの管理者として実行すると、そのアカウントへ設定されます。
- データ保存先は `%LOCALAPPDATA%/MKM/PiFidsManager` または `PiFidsDisplay`。接続ファイルは所有者・Administrators・SYSTEMだけが読める設定です。
- OSのスリープ・画面消灯・自動ログインは変更しません。電源投入から無操作で表示する運用では、設置時にこれらを別途決めます。
- 管理PCのOS時刻を基準にします。設置時に正しい日時を確認してください。元のWindows Time設定は data/time-before.reg と time-service-before.json に保存します。
- 既存インストールや使用中のポートを上書きしません。現在運用している試験環境をそのまま再インストールする用途ではありません。
- 途中で失敗した場合は結果と `%LOCALAPPDATA%/MKM/PiFidsSetup.log` を確認してください。自動で既存データを消したり、部分設定を上書きして再試行したりはしません。
- 停止はタスクスケジューラの MKM-PiFidsManager-* または MKM-PiFidsDisplay-* を停止・無効化します。専用接続ファイルを共有資料やGitへ保存しないでください。
