Pi-FIDS セットアップ手順
Setup Guide

管理PC・表示端末 / Management PC & Display PC
ZIP版 / ZIP setup · 2026-10-08

新規PC用の試験版です。既存の稼働中環境への上書き導入には使わないでください。新規PCへの一括導入・再起動検収は未完了です。

準備するもの

Windows 10/11 64bit、Microsoft Edge、管理者権限のある設置用Windowsアカウントを用意します。管理PCと表示端末は同じ設置LANに接続します。ZIPはUSBからローカルフォルダー（例 C:\PiFids-Setup）へ展開してください。

1. 管理PCをセットアップ

管理PCのLAN IPv4アドレスを固定またはルーターで予約します。信頼できる設置LANをWindowsの「プライベート」に設定し、日時が正しいことを確認します。「Install-Manager.cmd」を右クリックして「管理者として実行」。空港の3レターコード、IANAタイムゾーン、管理PCのLAN IPv4を入力します。例：SHI / Asia/Tokyo。海外例：ROR / Pacific/Palau、BKK / Asia/Bangkok。

2. 便・画像を登録

デスクトップの「Pi-FIDS Management」で管理画面を開き、最初の管理者のユーザー名とパスワード（12文字以上）を登録します。⑥ユーザー管理で担当者を追加します。オペレーターは①便情報・②表示切替、管理者は③以降を含む全項目を操作できます。便一覧を設定し、カウンター・ゲート用の画像と表示画面を登録します。管理画面は http://127.0.0.1:8800/ です。MKM Flight Webの利用空港・権限・接続は別途設定が必要です。このセットアップだけではWebから便は取り込まれません。

3. 表示端末の接続ファイルを作成

管理PCで「Pi-FIDS Add Display」を開きます。管理者でログインして、空港コード、端末ごとに固有のID（例 counter-02）、分かりやすい端末名を入力します。用途は 1=出発便一覧、2=到着便一覧、3=カウンター・ゲート画像。画像の場合は登録済み画面の番号を選びます。最後に表示された「端末ID.connection.json」だけを対象端末へUSB等で渡します。

4. 表示端末をセットアップ

表示に使うWindowsアカウントでログインします。ZIPをローカルへ展開し、専用接続ファイルをコピーします。「Install-Display.cmd」を右クリックして「管理者として実行」。接続ファイルのフルパスを入力します。受信、自動起動、Edgeの全画面表示、タスクバーの自動非表示、管理PCへの時刻同期を設定します。

5. 再起動して確認

管理PCと表示端末を再起動し、それぞれセットアップしたWindowsアカウントでログインします。管理画面と全画面表示が自動で開くことを確認します。管理画面②で画像を切り替え、③で端末一覧・現在の表示設定を確認します。便一覧の空港名・ロゴ・HH:MMの時計、時刻同期も確認します。⑧監査ログで更新者と変更前後を確認します。Web取り込みはMKM Flight Webと実行ユーザーの両方を記録します。監査記録は導入後からです。古いPCではログイン後に数分かかる場合があります。

困ったとき

何も出ない：管理PCが起動しているか、画像・便が登録されているか、接続ファイルがその端末用かを確認します。接続失敗：管理PCのIPと設置LANを確認します。既存環境・使用中のポート・登録済みIDは上書きしません。途中で失敗した場合はエラーを記録し、再実行前に途中の登録や設定を確認してください。Windowsが実行をブロックした場合は停止し、表示内容を担当者へ伝えてください。

運用・保守

自動表示はWindowsへのログイン後です。自動ログイン、スリープ、画面消灯は変更しません。全画面を閉じるには Alt+F4。自動起動の停止はタスクスケジューラの MKM-PiFidsManager-* / MKM-PiFidsDisplay-* を停止・無効化します。端末登録の削除は保存済み画面を遠隔消去する操作ではありません。

接続ファイルは端末専用の鍵です。共有フォルダーや配布ZIPへ入れず、USBのコピーは設置後に回収してください。管理PCのlan-auth.jsonを表示PCへ渡さないでください。

Before you start

Use Windows 10/11 64-bit, Microsoft Edge, and the intended Windows account with administrator rights. Connect the manager and displays to the installation LAN. Extract the ZIP to a local folder, for example C:\PiFids-Setup.

1. Set up the management PC

Reserve or fix its LAN IPv4 address. Set the trusted installation network to Private and check the PC date and time. Right-click Install-Manager.cmd and select Run as administrator. Enter the three-letter airport code, IANA time zone, and this PC’s LAN IPv4 address. Examples: SHI / Asia/Tokyo; ROR / Pacific/Palau; BKK / Asia/Bangkok.

2. Register flights and images

Open Pi-FIDS Management on the desktop and create the initial administrator (password: at least 12 characters). Add staff accounts in section 6. Operators can use sections 1 and 2; administrators can use all sections. Configure the flight board and register counter/gate images and layouts. The management page is http://127.0.0.1:8800/. MKM Flight Web airport permissions and connection settings are separate; setup alone does not import Web flight data.

3. Create a display connection file

On the manager, open Pi-FIDS Add Display and sign in as an administrator. Enter the airport, a unique terminal ID such as counter-02, and a descriptive terminal name. Select 1 for departures, 2 for arrivals, or 3 for a counter/gate image. For images, select a registered layout number. Transfer only the generated terminal-ID.connection.json to the intended display, for example using USB.

4. Set up the display PC

Log in as the Windows account that will run the display. Extract the ZIP locally and copy its dedicated connection file. Right-click Install-Display.cmd and select Run as administrator. Enter the full path to the connection file. Setup configures the receiver, startup after login, Edge fullscreen kiosk, taskbar auto-hide, and time synchronization with the manager.

5. Restart and verify

Restart both PCs and log in using their setup accounts. Verify automatic management and fullscreen startup. Switch images from management section ②; review terminals and current settings in section ③. Check airport names, logos, the HH:MM clock, and time synchronization. Review the actor and before/after changes in section 8 (Audit log). Web imports identify MKM Flight Web and the initiating user. Records begin when this feature is installed. Older PCs may need several minutes after login.

Troubleshooting

Blank display: check that the manager is running, flights/images exist, and the connection file belongs to this terminal. Connection failure: check the manager IP and LAN. Existing installations, occupied ports, and duplicate terminal IDs are not overwritten. Record any setup error and inspect partial registrations/settings before retrying. If Windows blocks execution, stop and report the message to the installer/support person.

Operation and maintenance

Automatic display starts after Windows login. Setup does not change automatic login, sleep, or screen-off settings. Close fullscreen with Alt+F4. Stop/disable MKM-PiFidsManager-* or MKM-PiFidsDisplay-* tasks in Task Scheduler to stop automatic startup. Deleting a terminal registration does not remotely erase its cached screen.

Connection files contain terminal credentials. Keep them out of shared folders and distribution ZIPs; remove transfer copies after installation. Never give manager lan-auth.json to a display PC.

MKM Flight Web — 自動／手動 · Automatic / Manual

①のWeb欄で管理者がモードを選んで保存します。初期設定は手動。連携には別途契約が必要です。自動は毎分確認し、画面を閉じても受信・公開します。未公開の手動変更は確認・公開を待ち、通信・検証失敗時は最後の公開を保持します。

An administrator chooses and saves the mode in section 1. Manual is the default. A separate subscription is required. Automatic mode checks every minute with the browser closed. Unpublished manual changes require review and publication. Connection or validation failures preserve the last published data.
