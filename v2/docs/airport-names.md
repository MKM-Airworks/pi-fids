# 空港コードと表示名

管理メニュー「5. 空港コード入力・更新」で、SHI・RORそれぞれの空港コードと表示名を登録する。「6. 時刻同期・修正」は従来の時刻管理。

コードは英字3文字。日本語・英語・中国語（簡体／繁体）・韓国語の名称を編集できる。表示便の言語が未入力なら英語、それも未入力なら元のコードを表示する。手入力の自由な行先名はそのまま表示する。

初期名称はHND・UKB・FUK・OKA・SHI・ROR。初期値は運用者が変更できる。空港コードの改名は新コード登録として扱い、既存便のコードは変更しない。

名称は管理端末のSQLiteに空港別で保存する。名称保存時に配信版を更新し、ローカル端末配信にairportNamesを追加する。表示端末では検証後に便情報と同一トランザクションで保存し、通信断・再起動後も保持する。MKM Flight Webのコード・API・配信形式は変更しない。

2026-10-07: Windows 11で42 Pythonテストが成功。実SHI Web公開便が受信端末のKobe・Fukuoka・Tokyo (Haneda)表記になることをブラウザで確認。多言語検索、英語へのフォールバック、未知コード・自由入力の維持もJavaScriptで確認した。
