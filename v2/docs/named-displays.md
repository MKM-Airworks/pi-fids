# 左メニューと名称による表示切替

管理画面は4ページに分け、左側に空港・英語／日本語切替を常設する。

1. フライト情報管理: Web取込み、下書き編集、公開。
2. チェックイン・ゲート表示管理: 登録した端末名と表示画面名を選択し、表示を切り替える。「便一覧」で標準画面へ戻す。
3. 端末の設定: 接続設定に一致する端末ID、運用上の端末名、表示終了時間を保存する。同じ画面内で「JX Business Class」などの表示画面名、表示種類、航空会社、ロゴ、案内画像を登録する。
4. ロゴ・画像登録: 画像に名称を付けて登録する。表示画面の登録ではこの名称から画像を選ぶ。

端末の表示切替はファイル名を指定せず、端末名・表示画面名から選択する。登録は空港単位で保存する。端末名は同じ空港内で重複できない。同じ表示画面名を保存するとその画面を更新する。既存端末の表示は自動変更せず、2の操作で反映する。端末設定の保存も現在の表示画像・モードを維持する。既存の画面IDは端末名として初期登録し、後から分かりやすい名称へ変更できる。

配信は従来のV2端末指示を使用し、受信端末は表示種類・画像を受け取る。名称登録と切替APIは管理端末の認証・空港制限を適用し、LAN側では公開しない。MKM Flight Web APIは変更しない。
