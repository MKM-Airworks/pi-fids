# ROR既存設備ガイドからの確認事項

2026-10-05に提供された4冊のガイドの本文を確認。資料は2020〜2022年版で、現在の稼働状況・設定・OSを保証するものではない。既存製品のAPI仕様は記載されておらず、直接接続できるとは判断しない。

## V2への対応

| ガイドに記載された操作 | V2の設計への反映 |
| --- | --- |
| AirDBで便の日付、到着／出発、行先、定刻を入力し、予定時刻・状態・ゲート等を更新 | ローカル管理側のフライト編集項目に対応。便の削除・復元も要件として記録 |
| Messengerで設置場所を選び、航空会社の画面を選択・適用 | 端末／画面IDごとの手動表示指示に対応 |
| Messengerの標準画面復帰、Adminの上書き解除 | 手動切替と標準設定への復帰を明示的な操作として設計 |
| Adminの端末、Zone、表示種別、標準ページ設定 | 設置場所・端末・画面を管理する。既存の仮想Workstationはそのまま複製せず、対応表で移行 |
| 小・中・大ロゴ、カウンター／搭乗口用の全面画像 | ロゴと案内画像を別アセットで配信・保存。1920×1080の既存画像を受け入れられるテンプレートを検討 |
| 順次ページの順番とページごとの秒数 | 表示プレイリスト設定として設計。便の言語切替設定とは別に持つ |
| 表示時間範囲、案内テキストの変更 | 空港・端末の表示条件とテンプレート設定に対応 |
| アプリ再起動とOS再起動 | 端末監視・運用機能の検討事項。Windows実機検証と権限設計が必要 |
| 火災警報による画面切替 | 置換対象か、既存警報連携を継続するか要確認。今回の試作では実装していない |

## 展開前に必要な情報

- 端末OS、32/64bit、ブラウザ、解像度、画面数、ネットワーク経路の遠隔確認。
- 端末・設置場所・標準表示・航空会社の割当表、使用権を確認した画像の受領。
- 既存の火災警報表示の扱い、航空会社ごとの編集権限、表示時間範囲の確認。
- 現場担当者による表示確認手順。ガイドでも切替後の実画面確認が求められているため、管理画面上の配信済み表示だけで完了としない。
