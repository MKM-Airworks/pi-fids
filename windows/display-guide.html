Pi-FIDS V2 表示端末 / Windows Display

日本語

  1. Windows 10／11 x64の表示端末で管理PCの指定URLを開き、ZIPをダウンロードしてすべて展開します。
  2. 管理者からこの端末専用の connection.json を受け取ります。
  3. 表示に使うWindowsアカウントで Install-Display.cmd を管理者として実行し、接続設定ファイルのフルパスを入力します。
  4. 端末を再起動して同じアカウントでサインインし、Kiosk画面と便情報を確認します。

English

  1. On the Windows 10/11 x64 display PC, open the manager’s download URL, download the ZIP, and extract all files.
  2. Obtain this terminal’s connection.json from your administrator.
  3. Using the Windows account that will show the display, run Install-Display.cmd as administrator and enter the full path to the connection file when prompted.
  4. Restart, sign in with the same account, and verify that the kiosk opens and shows flight data.
