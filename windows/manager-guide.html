Pi-FIDS V2 管理PC / Windows Manager

日本語

  1. Windows 10／11 x64の管理PCで、ZIPをローカルフォルダーにすべて展開します。
  2. 管理に使うWindowsアカウントで Install-Manager.cmd を管理者として実行します。空港コード、IANAタイムゾーン、空港LANのIPv4アドレスを入力します。
  3. デスクトップの Pi-FIDS Management を開き、初回管理者を設定します。「③ 端末の設定」で表示端末を登録し、端末専用の接続設定を発行します。
  4. 表示PCに http://管理PCのLANアドレス:8805/downloads を案内し、端末専用の接続設定を安全に渡します。
  5. 管理PCを再起動し、管理画面とLAN配布ページが開くことを確認します。

English

  1. Extract the entire ZIP to a local folder on the Windows 10/11 x64 management PC.
  2. Using the Windows account that will run Pi-FIDS, run Install-Manager.cmd as administrator. Enter the airport code, IANA time zone, and airport LAN IPv4 address.
  3. Open Pi-FIDS Management from the desktop, set up the first administrator, register the display terminal in Terminal settings, and issue its connection file.
  4. On the display PC, open http://MANAGER-LAN-IP:8805/downloads. Deliver its terminal-specific connection file securely.
  5. Restart the manager and confirm the management and LAN download pages open.
